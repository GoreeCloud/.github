# GoreeCloud support

This file provides default support routing for GoreeCloud repositories that do not define a more specific local support process.

## Bugs

For a reproducible defect in a repository that uses GitHub Issues, open a bug report and include enough information to reproduce the problem without exposing sensitive data.

## Feature ideas

Use the feature-request issue form when the repository accepts feature proposals. Explain the problem or user need before prescribing an implementation.

## Questions and usage help

Start with the repository's README, user documentation, installation instructions, troubleshooting guidance, and existing issues.

If GitHub Discussions is enabled for the repository, it may be appropriate for non-sensitive questions that are not defects.

For general GoreeCloud contact information, use the [official GoreeCloud contact page](https://www.goreecloud.com/contact/).

## Security issues

Do not use public support channels for vulnerabilities or sensitive security reports. Follow [SECURITY.md](./SECURITY.md).

## Sensitive information

Never post passwords, access tokens, private keys, private user data, internal-only infrastructure details, or other reusable secrets in a public issue, discussion, log excerpt, screenshot, or pull request.
